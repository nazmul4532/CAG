# Past Attempts

This folder holds earlier experiment notebooks and exports so the project root
can stay focused on the latest working setup.

- `notebooks/`: previous notebook versions from `v2` through `v9` plus dummy
  scratch runs.
- `notebook_exports/`: older HTML exports generated from those notebooks.
- `legacy_root_links/`: old root-level compatibility links that used to point at
  previous experiment output folders.

No data was deleted during organization. The heavy run outputs still live under
`outputs/experiments/`.
